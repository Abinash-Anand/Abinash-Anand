### Hey, I'm Abinash.

I'm a full-stack engineer who somehow ended up more interested in *why* software works than in just making it work. I started on the frontend — React, Angular, the usual suspects — and kept wandering further down the stack until architecture and system design became the part I actually look forward to.

Right now I'm doing an MSc in Software Technology at HFT Stuttgart, mostly because I wanted a real excuse to sit with the questions tutorials politely skip: what happens when this grows, who maintains it after me, and what breaks first.

I build things, break them on purpose, figure out why, and usually write about it somewhere. Think of this README as the lab notes.

<h2>WHAT'S ON MY RADAR</h2>

My foundation is frontend engineering — I care about interfaces that are genuinely pleasant to use, backed by code that doesn't fall apart the moment someone else has to touch it. But most of what excites me lately lives one layer down: how a system gets shaped before a single feature exists, how it holds up under real load, and how it ages over the following two years instead of just the first sprint.

I've also been spending real time with AI tooling lately — not as a rebrand, just as part of the job now. I use agentic coding workflows the same way I'd use any other tool: to move faster through the parts I already understand, while the architecture and the actual decisions stay mine.

<h2>THINGS I'm actively working on!</h2>
<h3>SynthGraph - My Open Source Project</h3>
<h4>SynthGraph - https://synthgraph.dev/ · Builder & Core Maintainer</h4>

A data lineage system for synthetic training data, born out of a Hack-Nation Venture Labs sprint. The idea: when a model misbehaves, you should be able to trace it straight back to the exact generator run and parameters behind its training data, instead of shrugging and retraining from scratch. I architected the NestJS/PostgreSQL backend — strict domain boundaries, hashed-key auth, 230+ tests gated by CI/CD — then built the Next.js dashboard and a Python SDK so capturing metadata doesn't get in anyone's way. Still actively maintained, now running as an independent open-source project.
