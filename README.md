<h2>🔥 CURRENT MISSION // READMYDAMNCOMMENTS</h2>

<table>
<tr>
<td width="67%" valign="top">

## `AI AUDIENCE INTELLIGENCE`

Creators get thousands of comments.

Most of them never get read.

Buried inside them are:

```text
QUESTIONS
CONTENT REQUESTS
PURCHASE INTENT
COMPLAINTS
COLLABORATION OPPORTUNITIES
PRODUCT FEEDBACK
```

So I built a pipeline that turns comment chaos into actionable audience intelligence.

```text
COMMENTS
   │
   ▼
┌─────────────┐
│ AI ENGINE   │
└─────────────┘
   │
   ▼
PATTERNS
   ├── Questions
   ├── Requests
   ├── Buying Signals
   ├── Complaints
   └── Content Ideas
```

**Stack**

`NestJS` `React` `TypeScript` `OpenAI` `Docker`
