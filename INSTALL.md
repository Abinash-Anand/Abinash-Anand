# Abinash // Killjoy README

## Files

- `README.md` — profile README
- `assets/hero.svg` — animated HUD hero

## Install

Copy the contents of this folder into the root of your profile repository:

```text
Abinash-Anand/
├── README.md
└── assets/
    ├── hero.svg
    ├── wave.svg
    └── telemetry.svg
```

Then commit and push.

The visual language uses a Killjoy-inspired palette and workshop/HUD aesthetic rather than relying on copied game UI assets.
